# Decisions — the project's decision log (single source of truth)

Every decision significant enough to constrain future work gets its own micro-ADR file here. This is the ONE place decisions live — chapters link here, they don't duplicate.

File: `YYYY-MM-DD-<short-slug>.md`. Format:
**Context / Options considered / Decision / Why / Consequences / Revisit if.**

Both executors use this dir: `/update-docs` and `/reflect` write here; the Gilfoyle cloud agent reads here before working a task and **PARKS if a task conflicts with a recorded decision**. Keep load-bearing decisions current, each with a clear `Revisit if`.
