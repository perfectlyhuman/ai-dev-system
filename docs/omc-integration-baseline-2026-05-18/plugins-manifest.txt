OMC Integration — Pre-Install Plugin & MCP Manifest
=====================================================

This file is a REDACTED structural snapshot of what was installed in
`~/.claude/settings.json` immediately before the OMC integration began.

The full settings.json file is NOT snapshotted here because it contains
embedded secrets (Bash permission patterns with credential values baked
in, MCP server `env` blocks with API keys and a GCP service-account
private key). See `omc-integration-plan-2026-05-18.md` Task 1 for the
redaction rationale.

For an authoritative rollback diff, compare your live `~/.claude/settings.json`
plugin and MCP entries against this manifest at rollback time.

## Statusline

Statusline configuration block present. OMC ships an optional `omcHud`
statusline preset; the integration plan does NOT enable it. If `omcHud`
appears in your statusline config after install, that is opt-in OMC
behavior and can be reverted by removing the entry.

## What this manifest does NOT capture (intentionally)

- Bash permission allowlist entries (contain credential values)
- MCP server `env` blocks (contain API keys + GCP private key)
- Any field whose value is or could be a secret

If full settings reconstruction is ever needed for rollback, the
authoritative source is the original `~/.claude/settings.json` on disk
at the time of rollback — not this manifest.
